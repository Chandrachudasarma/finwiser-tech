Design Rationale

Rendered DEAD on purpose

This node is the finish line that never fires. Its last frame is locked and undelivered because the slide is pure problem — it ends unresolved so the viewer feels the loss of the one output they needed. The next slide is the solution; this frame makes them crave it.

The dependency sink

④ can only run if ①②③ feed it — goals + holdings + surplus. The three green pills hand toward a broken arrow: because each upstream piece lives in a separate app, the final handoff never completes, so this crucial last step never starts. The dependency is shown, not claimed.

Colour / state system

Resolved green (#00b894) belongs to nodes ①②③, which work in isolation. This node is grey/dead — desaturated avatar, locked 🔒, empty unchecked boxes — with a faint red (#e94560 / #ff6b81) break accent on the snapped link and the "never delivered" stamp. Grey = dead, red = the handoff that breaks.
